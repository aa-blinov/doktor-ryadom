# Установка и уведомления

## Подключение

Откройте настройки пациента или аккаунт врача. В разделе «Приложение на устройстве» установите Рядом. В поддерживаемом браузере появится кнопка установки. На iPhone откройте сайт в Safari, выберите «Поделиться» → «На экран Домой» и запускайте приложение с этой иконки. Push на iPhone требует iOS 16.4 или новее. [Правила Apple](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/).

В настройках нажмите «Включить уведомления на устройстве» и разрешите их в системном окне. Затем нажмите «Проверить уведомление». Сервер отправляет проверку только подписке текущего аккаунта на этом устройстве; повторная проверка доступна через минуту. Сообщение о принятии сервером не гарантирует показ при отключённых системных уведомлениях или режиме фокусирования.

Выберите время, часовой пояс и сохраните настройки. Пациент получает напоминание в дни своего расписания, если ещё не отметил состояние. Пауза отключает напоминания. Врач отдельно включает ежедневную сводку; она приходит при наличии непросмотренных материалов. Ответы, имена пациентов и медицинские сведения в уведомления не включаются.

## Работа приложения

PWA кеширует интерфейс и статические файлы. API и медицинские записи не включаются в офлайн-кеш. После запуска без сети показано объяснение; для входа, загрузки и сохранения нужен интернет. При восстановлении соединения приложение повторяет проверку сеанса.

Обновления устанавливаются по кнопке «Обновить». Перед нажатием сохраните текущие ответы. Можно отложить обновление и продолжить работу. [Механизм Vite PWA](https://github.com/vite-pwa/vite-plugin-pwa/blob/main/docs/frameworks/react.md).

Нажатие уведомления открывает «Сегодня» у пациента или «Пациенты» у врача. Если приложение уже открыто, используется существующее окно. Выход из аккаунта отключает подписку этого устройства; после повторного входа уведомления нужно подключить снова.

## Повторная техническая проверка

Из `app/` выполните `node scripts/pwa-live-check.mjs`. Требуется установленный Chrome; путь задаётся через `CHROME_EXECUTABLE`, адрес сайта — через `PWA_ORIGIN`. Проверка создаёт вымышленный аккаунт врача и удаляет доступ после завершения. Для проверки пациента и попытки регистрации push задайте `PWA_REAL_PUSH=1`; для повторной проверки интерфейса после недоступного провайдера используйте также `PWA_SKIP_PROVIDER=1`. Снимки и JSON сохраняются в `.impeccable/review/`. Файлы `fixture` используют модель подписки.

`node scripts/pwa-update-check.mjs` открывает опубликованную версию и ждёт обновления до 55 секунд. Во время проверки во втором терминале публикуется новая сборка. Скрипт проверяет баннер и переход на новую версию; сам публикацию не выполняет.
