# Карта действий по экранам

Составлено по исходникам (`app/src`) на 2026-10-09. Маршруты в hash-роутере (`#/...`). Для каждого экрана: что видно, кнопки и ссылки, куда ведут, что происходит на сервере.

Обозначения: **→** переход, **API** запрос на сервер, **[модал]** подтверждение в окне, **[2 шага]** двойное подтверждение.

---

## 1. Пациент

Навигация: Сегодня `#/today`, История `#/history`, Практики `#/practices`, Врач `#/doctor`, Настройки `#/settings`.

### 1.1 Вход и регистрация (`Auth`, гость)
| Элемент | Действие | Результат |
|---|---|---|
| Переключатель «Я регистрируюсь как» | режим регистрации | поля Фамилия, Имя, согласие |
| Чекбокс «Разрешаю сохранять мои данные и записи» | обязательно для регистрации | кнопка входа неактивна без него |
| Кнопка входа/регистрации | API `auth/login` или `auth/register` | → `#/today` (пациент), `#/patients` (врач), `#/admin` (админ) |
| «Забыли пароль?» | → `#/forgot` | восстановление (`AccessRecovery`) |
| «Попробовать снова» (при ошибке сети) | повтор загрузки сессии | |

### 1.2 Онбординг (первый вход)
| Элемент | Действие | Результат |
|---|---|---|
| «Дальше» | следующий шаг | |
| «Назад» | предыдущий шаг (неактивна на первом) | |
| «Пропустить» | закрыть | → `#/checkin` |
| «Как пользоваться Рядом» (в настройках) | повторно открыть онбординг | |

### 1.3 Сегодня (`#/today`)
Если отметка за сегодня уже есть: карточка «Отметка за сегодня есть» с кнопкой **Открыть историю**. Иначе — полная форма отметки.

| Элемент | Действие | Результат |
|---|---|---|
| Самочувствие (5 лиц) | выбор значения | сохраняется черновик API `drafts` |
| Сон: часы и минуты | выбор | черновик |
| Тревога, Энергия, Обычные дела (шкалы) | выбор точки | черновик |
| Заметка врачу | ввод | черновик, статус «Сохраняем черновик…» → «Черновик сохранён» |
| **Сохранить отметку** | API `patient/checkins` | → `#/saved` (экран «Отметка сохранена») |
| **Открыть историю** (если отметка есть) | | → `#/history` |
| Баннер приглашения (`?invite=`) | **Посмотреть** | → `#/settings/connect` |
| «Последние 7 дней»: дни ≤ 6 дней назад | переход к редактированию | → `#/edit/:id` |
| **Мне плохо** (топбар) | [1 шаг] | → диалог подтверждения поверх текущего экрана |
| ↳ **Да, отправить** | API `patient/sos` | сигнал врачу (почта, уведомления) |
| ↳ **Отмена** | | диалог закрывается, адрес не меняется |

### 1.4 Отметка сохранена (`#/saved`)
| Элемент | Результат |
|---|---|
| **Посмотреть историю** | → `#/history` |
| **Подготовить сводку** | → `#/summary` (раздел удалён, открывается «Сегодня») |
| **На сегодня** | → `#/today` |

### 1.5 Редактирование записи (`#/edit/:id`)
| Элемент | Результат |
|---|---|
| **Сохранить исправления** | API `PUT` записи, версия растёт → назад |
| **Отмена** | назад (history.back, при отсутствии истории → `#/history`) |
| **История** (ссылка) | → `#/history` |

### 1.6 История (`#/history`)
| Элемент | Результат |
|---|---|
| Период (фильтр) | пересчёт списка и графиков |
| Тренд (график) | просмотр |
| Запись (**Открыть/Изменить**, `subtle`) | → `#/edit/:id` |
| **Показать все** / свернуть | раскрыть список (на телефоне 7 записей, на десктопе 14) |
| Опросники (`AssessmentReview`) | ответы пациента, просмотр результатов |
| **Подтвердить просмотр результата** (если врач ждёт) | API, отметка просмотра |

### 1.7 Практики (`#/practices`)
| Элемент | Результат |
|---|---|
| Поиск, фильтры «Направление», «Время» | список практик |
| Карточка практики | → `#/practice/:id` (если практика доступна в плане; иначе «Практика сейчас недоступна» → **К списку практик**) |
| **Все практики** | сброс фильтров |
| Пустое состояние (нет подключённого врача) | **Подключить врача** → `#/settings/connect` |

### 1.8 Практика (`#/practice/:id`)
| Элемент | Результат |
|---|---|
| Выбор отзыва (удобно / так же / неприятно) | |
| **Сохранить оценку** | API `patient/practices`, запись в историю |
| Заметка | сохраняется вместе с оценкой |

### 1.9 Врач (`#/doctor`)
| Элемент | Результат |
|---|---|
| **План врача** | → `#/plan` |
| **Подключить врача** (если не подключён) | → `#/settings/connect` |

### 1.10 План врача (`#/plan`)
Только просмотр. Назначения, опросники, рекомендации врача, записи приёма.

| Элемент | Результат |
|---|---|
| **Заполнить опросник** | → `#/assessment/:id` |
| **Отметка за сегодня**: **По назначению / Был пропуск / Не понадобился** (препарат) | API `patient/medication-logs` |
| **История отметок** (раскрыть) | просмотр |
| **Что вы заметили**: поле и **Сохранить наблюдение** | API `patient/experiences` |
| **Цели** / **На сегодня** | → `#/goals` / `#/today` |

### 1.11 Опросник (`#/assessment/:id`)
| Элемент | Результат |
|---|---|
| Варианты ответа | выбор, кнопка «Далее» активна после ответа |
| **Назад** | предыдущий вопрос |
| **Далее** / **Сохранить** (на последнем) | API, на последнем — сохранение и результат |
| **Подробнее о шкале** (`AssessmentMethodology`) | открыть методику |
| Ответ с пунктом безопасности (PHQ-9) | блок «Что делать» с 112 и контактом врача |
| **На сегодня** | → `#/today` |

### 1.12 Цели (`#/goals`)
| Элемент | Результат |
|---|---|
| **Добавить цель** (форма: «Новая цель», «Почему это важно») | API `goals`; при трёх активных кнопка неактивна, текст «Сначала завершите одну из текущих целей» |
| По цели: **Сохранить отметку** (статус: шаг / трудно / достигнута + заметка) | API `goal-logs` |
| По цели: **Завершить** | API, цель закрывается |
| **Отмена** (в форме отметки) | закрыть без сохранения |
| Статус «Ожидает просмотра» | ждёт врача, кнопка врача **Подтвердить просмотр отметки** |

### 1.13 Настройки (`#/settings`)
| Элемент | Результат |
|---|---|
| **Изменить пароль** (текущий, новый ≥ 12 символов) | API, сессии других устройств сбрасываются |
| **Выйти на других устройствах** | API `account/logout-others` |
| **Скачать мои данные** | файл архива |
| **Удалить аккаунт** → [модал] «Введите УДАЛИТЬ» + пароль | API `DELETE account`, выход |
| **Выйти из аккаунта** | → гость |
| Тема (светлая/тёмная) | переключение |
| **Как пользоваться Рядом** | онбординг |
| Напоминания: ежедневное, email, push, часовой пояс, пауза | API `settings` |
| **Проверить уведомление** | тестовое сообщение |
| Доступ врача: **Отозвать доступ** → [модал] **Отозвать доступ** / **Оставить доступ** | API `patient/revoke` |
| Записи: **Подключить врача** (код или ссылка) → **Проверить приглашение** → согласие → **Подключить врача** | API `patient/accept` |
| Ссылка «Подключить» на `#/settings/connect` | фокус на форме подключения |

## 2. Врач (подтверждённый)

Навигация: Пациенты `#/patients`, Аккаунт `#/settings`.

### 2.1 Список пациентов (`#/patients`)
| Элемент | Результат |
|---|---|
| **Пригласить пациента** | диалог: **Одноразовая ссылка** / **Код врача**, **Скопировать ссылку**, **Скопировать код**, **Закрыть** |
| Поиск «Найти пациента» | фильтр по имени |
| «Какие пациенты» (фильтр) | «Все пациенты» / с сигналами / без отметок |
| Строка пациента | → `#/patient/:id` |
| Сигналы в строке («Сигнал: мне плохо», «PHQ-9», «Нет отметок», «Низкое самочувствие») | видны без перехода |

### 2.2 Карточка пациента (`#/patient/:id`)
Вкладки: **Обзор**, **Цели**, **История**, **План наблюдения**.

**Обзор**
| Элемент | Результат |
|---|---|
| Блок «Сейчас» (отмечается N из M, самочувствие, сигналы) | просмотр |
| Сигнал SOS | сбрасывается при открытии карточки (`acknowledged`) |
| Новые записи пациента | **Подтвердить просмотр** (по каждой записи) |
| **Подтвердить все** | подтверждает все отметки сразу |
| **Показать просмотренные** | раскрыть подтверждённые |
| Опросники пациента (PHQ-9 пункт 9) | **Подтвердить просмотр результата** |

**Цели**
| Элемент | Результат |
|---|---|
| Цель и отметки пациента | просмотр |
| **Подтвердить просмотр отметки** | API `goal-logs/:id/review` |

**История**
| Элемент | Результат |
|---|---|
| Записи за период (14 на десктопе, 7 на телефоне) | **Показать все** |
| Графики и тренды | просмотр |

**План наблюдения** (`Care`, `план врача`)
| Элемент | Результат |
|---|---|
| Рекомендации: текст, цель, следующий приём, способ связи → **Сохранить рекомендации** | API `followups` |
| Назначения: название, схема, по необходимости, начало → **Добавить назначение** | API `medications` |
| По назначению: **Завершить назначение** [модал] | API `medications/:id/end` |
| Опросники: **Создать опрос** → конструктор (**Редактировать**, **Удалить**, **Поднять/Опустить вопрос**, **Сохранить опрос**, срок) | API `surveys` |
| Заметки/ощущения пациента | просмотр |
| **Сохранить план** (режим, практики, напоминания) | API `plan` |

### 2.3 Аккаунт врача (`#/settings`)
| Элемент | Результат |
|---|---|
| Профиль: Специальность, Клиника, Адрес, Стаж, О себе, Образование, Курсы, Опыт, Что важно знать | **Сохранить профиль** |
| **Загрузить фото** / **Удалить фото** | |
| Документы: **Прикрепить документ** (к записи, раздел, показывать пациентам) | |
| Уведомления: время сводки, пауза | **Сохранить уведомления** |
| Код / ссылка врача | **Скопировать** |
| Изменить пароль, выйти на других устройствах, скачать данные, удалить аккаунт | как у пациента |
| Выйти из аккаунта | → гость |

### 2.4 Не подтверждённый врач (`DoctorVerification`)
Экран вместо списка пациентов, пункт меню «Подключение».

| Элемент | Результат |
|---|---|
| Поля: Специальность, Номер лицензии или диплома, Город, Комментарий администратору | |
| **Отправить заявку** | API `doctor/verification`, статус «Заявка на проверке» |
| **К пациентам** | → `#/patients` (остаётся экран заявки, пока не подтверждено) |

## 3. Администратор

Навигация: Заявки врачей `#/admin`, Врачи `#/admin/doctors`, Пациенты `#/admin/patients`, Журнал `#/admin/audit`, Аккаунт `#/settings`.

### 3.1 Заявки врачей (`#/admin`)
| Элемент | Результат |
|---|---|
| Карточка заявки: специальность, город, лицензия, комментарий врача | просмотр |
| Комментарий врачу (поле) | подсказка «Чтобы запросить уточнение или отклонить заявку, напишите комментарий врачу» (пока поле пустое) |
| **Подтвердить** | API decision `approve`, врач получает доступ |
| **Запросить уточнение** (нужен комментарий) | API `needs_info`, письмо врачу |
| **Отклонить** (нужен комментарий) | API `reject`, письмо врачу |

### 3.2 Врачи (`#/admin/doctors`)
| Элемент | Результат |
|---|---|
| Поиск по имени или почте | фильтр |
| Карточка: статус проверки | просмотр |
| **Заблокировать** / **Разблокировать** | API block, сессии сбрасываются |

### 3.3 Пациенты (`#/admin/patients`)
Имена и почты не показываются, только «Пациент N», дата и статус.

| Элемент | Результат |
|---|---|
| **Заблокировать** / **Разблокировать** | API block |

### 3.4 Журнал (`#/admin/audit`)
Только просмотр. Содержимое записей не показывается.

### 3.5 Аккаунт администратора (`#/settings`)
Изменить пароль, выйти на других устройствах, скачать данные, удалить аккаунт, тема, выход. Как у остальных ролей.

## Известные пробелы

- На экране «Отметка сохранена» кнопка **Подготовить сводку** ведёт на `#/summary`, а этого маршрута больше нет: открывается «Сегодня». Кнопку стоит убрать или переименовать.
- Строки про врача в «Плане наблюдения» (опросники, назначения, сохранение плана) и про вкладку «Обзор» сверены по коду, но кликами на проде не проверялись.
- Опросник и план врача: на мобильном длинная форма отметки (см. отдельный разбор).
- Карточка врача у пациента без заполненного профиля показывает только имя (исправлено в `49aed22`).
