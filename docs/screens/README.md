# Экраны первой сборки

Скриншоты из работающего браузерного сценария. Все аккаунты и записи на изображениях созданы тестом и являются вымышленными.

- [Кабинет пациента, компьютер](patient-desktop.png)
- [Карточка пациента у врача](doctor-desktop.png)
- [Кабинет пациента, телефон](patient-mobile.png)
- [Короткий опрос, телефон](question-mobile.png)

Схема взаимодействий и состояния экранов: [SCREENS.md](../SCREENS.md).

Онбординг: [пациент, ПК](onboarding-desktop.png), [пациент, телефон](onboarding-mobile.png), [врач](onboarding-doctor.png). Иллюстрации показывают примеры, все аккаунты на снимках вымышлены.

Сводки перед приёмом: `report-patient-desktop.png`, `report-patient-320.png`, `report-doctor-desktop.png`, `report-doctor-mobile.png`. В сценарии используются вымышленные данные.

План врача и безопасность: [care-patient-desktop](care-patient-desktop.png), [care-patient-320](care-patient-320.png), [care-patient-observation-320](care-patient-observation-320.png), [care-doctor-desktop](care-doctor-desktop.png), [care-doctor-form-320](care-doctor-form-320.png), [account-patient-desktop](account-patient-desktop.png), [account-patient-save-320](account-patient-save-320.png). На viewport-снимках мобильные формы показаны целиком; full-page снимки служат обзором страницы.

PWA: [без сети, 320 px](pwa-offline-mobile.png), [обновление](pwa-update-desktop.png), [настройки врача](pwa-doctor-settings-320.png), [настройки пациента](pwa-patient-settings-320.png). Снимки `pwa-patient-connected-fixture-*` показывают моделируемую подписку для проверки элементов интерфейса и не подтверждают доставку через push-провайдера.
