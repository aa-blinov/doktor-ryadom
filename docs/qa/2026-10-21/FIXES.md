## Продуктовые решения, которые зафиксированы в коде

| Вопрос | Решение |
|---|---|
| Как долго можно править отметку | Только сегодняшняя запись. Старые записи — только чтение (`docs/user-paths.md`). |
| Какие даты можно отмечать | Сегодня и два прошедших дня (чтобы можно было наверстать). Будущие — отказ. |
| Отметка приёма препарата | Одна отметка на день; чтобы исправить — удалить прежнюю и поставить новую. |
| Отзыв о враче | Один отзыв на пациента на врача, публикуется один раз; чтобы изменить — удалить прежний и опубликовать новый. |
| Блокировка аккаунта | Разрывает связь с врачом и удаляет план. Связь не восстанавливается при разблокировке — нужно новое приглашение и новое согласие пациента. |
| Кабинет неподтверждённого врача | Закрыт целиком, кроме подачи заявки на верификацию. |
| Выгрузка | По роли: пациент — своё без клинических полей, врач — свои практики и данные только тех пациентов, которых он ведёт сейчас. |
