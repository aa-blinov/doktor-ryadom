# Пути к целевым действиям врача: клики

> Оценка по коду, не проверено в браузере.

Считается: каждый клик или переключение вкладки, которое меняет вид; открытие выпадающего списка тоже считается (1). Ввод текста в поле считается 1 действием, независимо от длины. Прокрутка не считается. Раскрытие `<details>` считается 1 кликом.

Старт: врач уже вошёл и открыт `#/patients` (0 кликов). При первом входе появляется модалка обучения (3 шага «Дальше»), она добавляет до 3 кликов один раз.

## Примечания
- Карточка открывается на последней вкладке этой сессии (`sessionStorage`), а не всегда на «Обзоре». Тогда первый клик по нужной вкладке может не понадобиться: счёт меняется на -1, в таблице он не учтён.
- Мобильный вид: вкладки заменены select «Раздел карточки пациента». Выбор раздела = 2 клика (открыть select, выбрать).
- Все цифры посчитаны по коду. Фактическое число кликов и расположение элементов в браузере не проверялось.
