# Карточка пациента: Цели

> Оценка по коду, не проверено в браузере.

**Маршрут:** `#/patient/:id`, вкладка «Цели» (`value="goals"`).
**Файл:** `app/src/Goals.tsx`, `Goals` с `doctor=true`.
**Назначение:** посмотреть личные цели пациента и его отметки по шагам.

## Элементы, которые действуют
Для врача действий нет. Кнопок «Добавить цель», «Завершить», «Сохранить отметку» врачу не показывается (они только в режиме пациента).

## Что показано
- Заголовок «Личные цели пациента» и подсказка «Цели формулирует пациент».
- Активные цели (закрытые не показываются): название, причина.
- По каждой цели до 5 последних отметок: статус («Сделал(а) шаг», «Возникла трудность», «Достиг(ла) цели»), дата, заметка.
- Статус отметки: «Врач подтвердил просмотр», «Просмотрено предыдущим врачом» или «Ожидает просмотра». Текст «Ожидает просмотра» ни на что не ссылается.

## Переходы
Нет. Экран только для чтения.

## Данные из API
`GET /api/doctor/patients/:id/data` (поля `goals`, `goalLogs` с `reviewed_at`, `reviewer_id`).

## Замечания
- Подтверждение просмотра отметки цели восстановлено: кнопка «Подтвердить просмотр отметки» в `Goals.tsx`, вызывает `POST /api/doctor/patients/:id/goal-logs/:logId/review`. Эндпоинт `POST /api/doctor/patients/:id/goal-logs/:logId/review` (`care.ts`) существует, но ни один файл `src/` его не вызывает. Цель (e) в [README](../README.md) не выполняется.
- На вкладку «Обзор» счётчик «Отметки целей, N» ведёт сюда, но ответить на него нельзя.
