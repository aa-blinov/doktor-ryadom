# Аккаунт врача

> Оценка по коду, не проверено в браузере.

**Маршрут:** `#/settings` (пункт «Аккаунт» в меню врача).
**Файлы:** `app/src/Doctor.tsx` (блок-шапка), `DoctorCode.tsx`, `ProfileSettings.tsx`, `ProfileDocuments.tsx`, `DoctorReminders.tsx`, `AccountSettings.tsx`, `Onboarding.tsx`.
**Назначение:** код врача, профиль для пациентов, уведомления, безопасность аккаунта.

## Блоки сверху вниз

1. **Шапка:** имя, email, «Как пользоваться Рядом» (открывает модалку обучения, 3 шага). Текст: пациенты подключаются по приглашению и могут отозвать доступ.
2. **Ваш код врача** (`DoctorCode`): код и ссылка `${origin}/?invite=CODE`, readOnly. Кнопки «Скопировать код», «Скопировать ссылку». Код постоянный. Пока врач не верифицирован, показан текст «Подключение пациентов станет доступно после проверки».
3. **Профиль врача** (`ProfileSettings`): ФИО, фото («Загрузить фото», «Удалить фото»), специальность, клиника, адрес приёма, о себе, с чем работает, образование, «Что важно знать врачу», дата рождения. Кнопка «Сохранить профиль» (неактивна, пока имя короче 2 символов).
4. **Документы** (`ProfileDocuments`): «Прикрепить документ», раздел, привязка к записи, «Показывать подключённым пациентам» (переключатель), скачать, заменить.
5. **Уведомления врача** → [reminders.md](reminders.md).
6. **Аккаунт и безопасность** (`AccountSettings`): «Подтвердить email», «Изменить пароль», «Выйти на других устройствах», «Скачать мои данные», «Коды восстановления доступа», «Удаление аккаунта» (ввести УДАЛИТЬ и пароль). Блок PWA-установки.

Выход и смена темы — в боковом меню и в шапке на мобильном.

## Переходы
Нет переходов за пределы страницы, кроме ссылок «Источник» (внешние) и кнопки модалки обучения.

## Данные из API
- `GET /api/doctor/code` (код и `active`).
- `GET /api/profile`, `PUT /api/profile`, `PUT /api/profile/photo`, `/api/profile/documents`.
- `GET /api/auth/capabilities`, `POST /api/account/verify-email`, `POST /api/account/password`, `POST /api/account/logout-others`, `GET /api/account/export`, `POST /api/account/recovery-codes`, `DELETE /api/account`.

## Замечания
- Изменение ФИО или специальности сбрасывает верификацию профиля (`profiles.ts`). UI это предупреждает.
- Блок безопасности пишет: «Для подтверждения профиля передайте администратору сведения о квалификации». Подтверждение делается вне интерфейса.
- Удаление аккаунта врача обезличивает запись (`account.ts`, «Удалённый врач»).
