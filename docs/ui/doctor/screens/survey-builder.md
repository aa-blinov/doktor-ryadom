# Карточка пациента: Мои опросы (конструктор и назначение)

> Оценка по коду, не проверено в браузере.

**Маршрут:** нет отдельного. Блок «Мои опросы» внизу вкладки «План наблюдения» (`#/patient/:id`).
**Файл:** `app/src/SurveyBuilder.tsx`, `SurveyBuilder`; схема в `app/src/surveys.ts`.
**Назначение:** создать свой опрос в личной библиотеке врача и назначить его пациенту.

## Элементы, которые действуют

| Элемент | Действие | Переход |
|---|---|---|
| «Создать опрос» | открывает редактор | редактор |
| «Назначить свой опрос» (карточка шаблона) | `POST /api/doctor/patients/:id/surveys` с `templateId` и датой = сегодня | остаётся, «Сохранено» |
| «Редактировать» (карточка) | открывает редактор с копией шаблона | редактор |
| «Убрать» (карточка) | подтверждение, затем архивирует шаблон; уже назначенные остаются | — |
| «Вопросы, источник и методика» (details) | раскрыть | — |
| Редактор: «Выше», «Ниже», «Удалить», «Добавить вопрос» (до 12) | порядок и состав вопросов | — |
| Редактор: «Сохранить опрос» | `POST /api/doctor/surveys` или `PUT` с `expectedVersion` | закрывает редактор, «Опрос сохранён в вашей библиотеке» |
| Редактор: «Отмена» | подтверждение, закрывает без сохранения | — |

Типы вопроса: числовая шкала 0–10, один вариант (2–8 вариантов), свободный текст. Для каждого вопроса есть переключатель «Обязательный вопрос».

## Данные из API
- `GET /api/doctor/surveys`: библиотека шаблонов врача.
- `POST` / `PUT` / `DELETE /api/doctor/surveys[/:id]`: сохранение и архив. Лимит 50 шаблонов.
- `POST /api/doctor/patients/:id/surveys`: назначение пациенту.

## Замечания
- После назначения виден только текст «Сохранено»: назначенный, но не пройденный свой опрос в интерфейсе врача не показан.
- Пациент видит назначенный опрос в «Опросники от врача» и заполняет его на `#/assessment/:id`.
- Если шаблонов нет, блок показывает «Пока нет своих опросов». Для назначения сначала нужно создать шаблон.
