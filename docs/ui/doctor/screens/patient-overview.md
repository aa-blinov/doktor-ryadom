# Карточка пациента: Обзор

> Оценка по коду, не проверено в браузере.

**Маршрут:** `#/patient/:id`, вкладка «Обзор» (по умолчанию в новой сессии).
**Файл:** `app/src/Doctor.tsx`, `PatientDetail`; `app/src/AppointmentOverview.tsx`; сводка в `app/src/appointment.ts`.
**Назначение:** сводка перед приёмом: что требует внимания, состояние, динамика.

## Элементы, которые действуют

| Элемент | Действие | Переход |
|---|---|---|
| «← Все пациенты» | назад | [patients-list.md](patients-list.md) |
| Вкладки: Обзор, Цели, К приёму, История, План наблюдения, Записи приёма | смена вкладки без смены hash | соответствующий файл |
| Select «Раздел карточки пациента» (мобильный) | то же | то же |
| «Открыть» / «Открыть результат» у пунктов «На что обратить внимание» | смена вкладки | см. ниже |

Пункты блока «На что обратить внимание»:
- «PHQ-9: нужно отдельно просмотреть ответ на пункт 9» → вкладка «План наблюдения». Подтверждение там не находится, оно во вкладке «История» (см. замечание).
- «Опросники, N» → «План наблюдения».
- «Отзывы о практиках, N» → «История».
- «Отметки целей, N» → «Цели».
- Сигналы из отметок («Сигналы» по записям) — без перехода.

## Блоки без действий
«Состояние» (последняя отметка: дата, самочувствие), «Динамика» (сравнение с предыдущим периодом), «Ход периода» (графики, если ≥3 точек), «Что хочет обсудить пациент», «Согласованная цель», «Расчёты и препараты». Над вкладками — блок «О пациенте» (`PatientProfileDetails`), только чтение.

## Данные из API
`GET /api/doctor/patients/:id/data`. Этот же запрос пометил SOS пациента как просмотренный (см. [clicks.md](../clicks.md), пункт b).

## Замечания
- Пункт PHQ-9 ведёт на «План наблюдения», где нет блока подтверждения. Вероятно, ссылка должна вести на «История» (`appointment.ts`, `tab:'plan'`). По коду: ошибка или намеренно, не выяснено.
- SOS в блоке «На что обратить внимание» не показывается: `signals()` работает только по отметкам.
