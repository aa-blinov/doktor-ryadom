# Список пациентов

> Оценка по коду, не проверено в браузере.

**Маршрут:** `#/patients` (любой маршрут врача, кроме `/patient/:id` и `/settings`, показывает этот же список).
**Файл:** `app/src/Doctor.tsx`, `DoctorWorkspace`.
**Назначение:** показать подключённых пациентов и быстро найти тех, кому нужно внимание.

## Элементы, которые действуют

| Элемент | Действие | Переход |
|---|---|---|
| «Пригласить пациента» (шапка) | `POST /api/doctor/invites`, открывает модалку | [invite.md](invite.md) |
| «Найти пациента» (поле) | фильтр по имени, на клиенте | — |
| Select «Какие пациенты» | фильтр: Требуют внимания / Все пациенты (по умолчанию) / Новые материалы / Без отметок | — |
| Строка пациента (`<a>`) | открыть карточку | [patient-overview.md](patient-overview.md) |
| «Создать приглашение» (пустое состояние, пациентов нет) | то же, что «Пригласить» | [invite.md](invite.md) |
| «Повторить» (ErrorBox) | перезагрузка списка | — |

## Фильтры (клиентская логика)
- **Требуют внимания:** `attentionFlags(p)` не пуст. Флаги: SOS (`open_sos`), PHQ-9 пункт 9 (`pending_safety`), нет отметок ≥3 дней или ни одной, самочувствие ≤2 (`shared.ts`, `attentionRules`).
- **Новые материалы:** сумма `pending_reports + pending_assessments + pending_practices + pending_goals` больше 0.
- **Без отметок:** `count = 0`.

## Порядок строк (сервер)
`GET /api/doctor/patients` сортирует: `open_sos DESC`, `pending_safety DESC`, сумма pending DESC, имя. Срочные пациенты наверху и без фильтра.

## Что видно в строке (без перехода)
Бейджи флагов, «Новых материалов: N», последняя отметка (дата), самочувствие, число отметок.

## Данные из API
`GET /api/doctor/patients`.

## Замечания
- Строка показывает дату и самочувствие последней отметки: ответ на «последний check-in» без перехода.
- Пустое состояние «Начните с одного пациента» содержит три шага и кнопку приглашения.
- Ошибка приглашения (например, врач не верифицирован) выводится ErrorBox над списком.
