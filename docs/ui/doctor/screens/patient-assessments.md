# Карточка пациента: Опросники в истории (просмотр результатов)

> Оценка по коду, не проверено в браузере.

**Маршрут:** `#/patient/:id`, вкладка «История», блок «Опросники в истории».
**Файл:** `app/src/Care.tsx`, `AssessmentReview`, `AssessmentSafety`; источник и методика в `AssessmentMethodology.tsx`.
**Назначение:** посмотреть пройденные пациентом опросники и подтвердить просмотр результата.

## Элементы, которые действуют

| Элемент | Действие | Переход |
|---|---|---|
| «Подтвердить просмотр результата» | `POST /api/doctor/patients/:id/assessments/:aid/review` | остаётся на вкладке, «Просмотр подтверждён» |
| «Исходные ответы» (details) | раскрыть список ответов | — |
| Ссылка «Источник» | внешняя ссылка | — |

Кнопка подтверждения есть только у результатов, которые ещё не подтверждены. Показываются только опросники, назначенные текущим врачом и уже пройденные.

## Что показано
- Название, балл, дата заполнения.
- Статус: «Врач подтвердил просмотр» или «Ожидает просмотра врачом».
- PHQ-9 с ответом на пункт 9 больше нуля: оранжевый блок «Пункт 9: нужна отдельная оценка». Показаны согласованная связь и порядок просмотра, введённые врачом при назначении.
- Текст: «Подтверждение просмотра не заменяет оценку».

## Данные из API
`GET /api/doctor/patients/:id/data` (поле `assessments`).

## Замечания
- Назначенные, но не пройденные опросники здесь не видны. В блоке «План наблюдения» их видно только для стандартных опросников («Ждёт ответа пациента»).
- Счётчик «Опросники, N» на «Обзоре» ведёт на «План наблюдения», но кнопка подтверждения находится здесь, во вкладке «История». Это расхождение по коду (см. [patient-overview.md](patient-overview.md)).
