# Карточка пациента: План наблюдения

> Оценка по коду, не проверено в браузере.

**Маршрут:** `#/patient/:id`, вкладка «План наблюдения» (`value="plan"`).
**Файл:** `app/src/Doctor.tsx`, `PlanForm`; ниже `AssessmentResults` (`app/src/Care.tsx`), который показывает блок «Мои опросы» (`SurveyBuilder.tsx`).
**Назначение:** задать частоту отметок, практики и опросники, которые пациент получит.

## Элементы, которые действуют

| Элемент | Действие | Переход |
|---|---|---|
| Select «Частота» | каждый день / три раза в неделю / раз в неделю | — |
| Чекбоксы «Сон», «Тревога», «Энергия», «Обычные дела» | какие вопросы в отметке | — |
| Поле «Небольшое действие» (до 180 символов) | текст рекомендации | — |
| Чекбоксы практик + «Источник» (внешняя ссылка) | включить практику в план | — |
| Чекбоксы опросников (GAD-7, PHQ-2, WHO-5, PHQ-9) | назначить опросник | — |
| «Связь с врачом», «Порядок просмотра ответов» | появляются при выборе PHQ-9; обязательны, ≥5 символов | — |
| «Сохранить план» | см. ниже | — |
| Блок «Мои опросы» | см. [survey-builder.md](survey-builder.md) | — |

Опросник, уже назначенный этому пациенту, показан с disabled-чекбоксом: «Ждёт ответа пациента» или «Пройден».

## «Сохранить план»
1. `PUT /api/doctor/patients/:id/plan` с полями плана.
2. Для каждого нового выбранного опросника: `POST /api/doctor/patients/:id/assessments`, дата = сегодня. Для PHQ-9 отправляются контакт и порядок просмотра.
3. Успех: «План сохранён». Ошибка: ErrorBox на этом же экране.

## Данные из API
`GET /api/doctor/patients/:id/data` (`plan`, `assessments`). Сохранение: `PUT .../plan`, `POST .../assessments`.

## Замечания
- Поле `reviewNote` плана в интерфейсе не редактируется. Значение по умолчанию задано в `shared.ts` (`defaultPlan`). Кнопка «Сохранить план» активна, пока оно не короче 5 символов.
- Повторное назначение того же опросника на ту же дату сервер отклоняет (409).
- Пациенту стандартный опросник появляется в «Опросники от врача» с датой.
