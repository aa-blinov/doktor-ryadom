# Карточка пациента: Опыт практик (отзывы)

> Оценка по коду, не проверено в браузере.

**Маршрут:** `#/patient/:id`, вкладка «История», блок «Опыт практик».
**Файл:** `app/src/PracticeReview.tsx`, `PracticeReview`.
**Назначение:** прочитать отзывы пациента о практиках и подтвердить их просмотр.

## Элементы, которые действуют

| Элемент | Действие | Переход |
|---|---|---|
| «Подтвердить просмотр отзыва» (у каждого отзыва, не просмотренного этим врачом) | `POST /api/doctor/patients/:id/practices/:logId/review` | остаётся на вкладке, «Просмотр подтверждён» |

## Что показано
- Сортировка: сначала отзывы, которые этот врач ещё не просмотрел, затем по дате (новые выше).
- Для каждого: название практики, отзыв (Комфортно / Без изменений / Неприятно), дата и время, заметка пациента.
- Подпись: «После неприятного опыта упражнение перестаёт предлагаться. Обсудите отзыв и при необходимости измените план наблюдения.»
- Пустое состояние: «Пациент пока не сохранил отзывы о практиках».

## Данные из API
`GET /api/doctor/patients/:id/data` (поле `practices`); подтверждение через `.../practices/:logId/review`. Ошибка выводится ErrorBox над блоком.

## Замечания
- Если отзыв уже просмотрел другой врач, этот врач всё равно видит кнопку (статус считается по `reviewer_id`).
- Счётчик «Отзывы о практиках, N» на «Обзоре» ведёт сюда.
