# Приглашение пациента (модалка)

> Оценка по коду, не проверено в браузере.

**Маршрут:** отдельного нет. Модалка «Приглашение пациенту» открывается на `#/patients`.
**Файл:** `app/src/Doctor.tsx`, `createInvite`, `Modal`.
**Назначение:** выдать одноразовую ссылку для подключения пациента (действует 7 дней).

## Элементы, которые действуют

| Элемент | Действие | Переход |
|---|---|---|
| «Пригласить пациента» (шапка списка) | `POST /api/doctor/invites`, при успехе открывает модалку | модалка |
| «Одноразовая ссылка» (поле, readOnly) | при фокусе выделяет весь текст | — |
| «Скопировать ссылку» | `navigator.clipboard`, текст меняется на «Скопировано» | — |
| «Закрыть» и крестик | закрыть модалку | `#/patients` |

## Формат ссылки
`${origin}/?invite=<token>`. Токен показан в модалке; в базе хранится только его хеш (`digest`).

## Данные из API
`POST /api/doctor/invites` возвращает `{token, expires}` (срок 7 дней).
Ошибка 403 без верификации врача выводится над списком, модалка не открывается.

## Замечания
- Приглашение одноразовое: при принятии `invites.used = 1` (`index.ts`, `POST /api/patient/accept`).
- Постоянный код врача в модалку не входит. Он есть в `#/settings` (см. [settings.md](settings.md)).
- Пациент получает ссылку и принимает её после входа или регистрации (`Auth` в `App.tsx` читает `?invite=`).
- Текст модалки: «Приглашение не даёт доступ без согласия пациента».
