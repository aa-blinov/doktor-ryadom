# Уведомления врача

> Оценка по коду, не проверено в браузере.

**Маршрут:** блок «Уведомления врача» в `#/settings`.
**Файлы:** `app/src/DoctorReminders.tsx` (`DoctorReminders`), `app/src/ReminderSettings.tsx` (`ReminderSettings`, `doctor=true`).
**Назначение:** когда и как присылать сводку по новым материалам и SOS.

## Элементы, которые действуют

| Элемент | Действие | Переход |
|---|---|---|
| «Время ежедневной сводки» (time) | задаёт время сводки | — |
| «Часовой пояс» (Select, с поиском) | задаёт пояс | — |
| «Ежедневная сводка новых материалов» (переключатель, только врач) | одна сводка в день, если есть непросмотренное | — |
| «Напоминать по email» (переключатель, если email подтверждён) | письма без медицинских данных | — |
| «Включить / Отключить уведомления на устройстве» | запрос разрешения браузера, подписка push | — |
| «Проверить уведомление» (после подключения устройства) | отправляет тестовый push | — |
| «Использовать уведомления для напоминаний» (после подключения) | переключатель | — |
| «Поставить уведомления на паузу» | переключатель | — |
| «Сохранить уведомления» | `PUT /api/settings` | «Настройки уведомлений сохранены» |

## Данные из API
`GET /api/settings`, `PUT /api/settings`, `GET /api/notifications` (ключ push и список подписок), `POST /api/notifications/subscribe`, `.../unsubscribe`, `.../test`.

## Замечания
- SOS отправляется всем связанным врачам по push и email независимо от этих настроек (`jobs.ts`, комментарий в коде).
- Текст под поясом на iPhone: уведомления доступны после добавления приложения на экран «Домой».
- Часовой пояс, email и устройство не зависят от роли в коде: это общие блоки с пациентом. Только переключатель сводки показан врачу отдельно.
