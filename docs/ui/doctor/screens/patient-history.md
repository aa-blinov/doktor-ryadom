# Карточка пациента: История

> Оценка по коду, не проверено в браузере.

**Маршрут:** `#/patient/:id`, вкладка «История» (`value="history"`).
**Файл:** `app/src/Patient.tsx`, `History` (с `doctor`); ниже в той же вкладке `AssessmentReview` и `PracticeReview`.
**Назначение:** динамика самоотчётов пациента и подтверждение просмотра опросов и практик.

## Элементы, которые действуют

| Элемент | Действие | Переход |
|---|---|---|
| Сегмент «14 дней / 30 дней / 90 дней» (по умолчанию 30) | фильтр графиков и списка по дням | — |
| «Экспорт CSV» (шапка, неактивен без записей) | скачивает `patient-history.csv` (на клиенте) | — |
| «Подтвердить просмотр результата» | см. [patient-assessments.md](patient-assessments.md) | — |
| «Подтвердить просмотр отзыва» | см. [patient-practices.md](patient-practices.md) | — |

## Что показано
- Блок «Изменения для обсуждения»: наблюдаемые ответы (`signals`), только если есть что показать. Подпись: клиническую значимость оценивает врач.
- Графики (с линией тренда): самочувствие, сон, тревога, энергия, обычные дела.
- «Записи по дням»: список отметок за период, с заметками.
- Ниже: «Опросники в истории», «Опыт практик».

## Данные из API
`GET /api/doctor/patients/:id/data`. Экспорт CSV использует уже загруженные данные, отдельного запроса нет.

## Замечания
- Пустое состояние: «История начнётся с первой отметки» (пациент ещё не отмечался).
- Все блоки вкладки лежат на одной длинной странице. Подтверждение опроса с пунктом 9 требует прокрутки вниз мимо графиков и списка.
- Пропуски остаются пропусками: текст «Самоотчёты пациента. Пропуски остаются пропусками.»
