# История

Маршрут: `#/history`. Файл: `app/src/Patient.tsx` (`History`).

## Состав
- Переключатель периода: 14, 30, 90 дней (по умолчанию 30).
- График самочувствия, блок «Сон» (при отсутствии данных «Пока нет данных»), сворачиваемый блок «Тревога, энергия и обычные дела».
- Список записей с кнопкой «Исправить запись» у каждой записи.
- Опросники (`AssessmentReview`) под списком, если есть.

## Действия
| Элемент | Куда ведёт |
|---|---|
| Исправить запись | `#/edit/:id` (кнопка только у записи за сегодня) |
| Период 14/30/90 | Остаётся, фильтрует список |
