# Библиотека практик

Маршрут: `#/practices`. Файл: `app/src/PracticeLibrary.tsx`.

## Содержимое
Список практик, которые назначил врач. Фильтры: поиск, направление, время. Если врач не назначил ни одной, показывается «Врач пока не добавил практики».

## Действия
| Элемент | Куда ведёт |
|---|---|
| Карточка практики | `#/practice/:id` |

## Замечание
Без подключённого врача раздел пустой. Пациент, который не подключил врача, видит пустую страницу из нижней навигации.
