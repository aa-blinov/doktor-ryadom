# Практика

Маршрут: `#/practice/:id`. Файл: `app/src/Patient.tsx` (`PracticeFlow`), `app/src/PracticeVisual.tsx`.

## Шаги
Начать практику, выполнить по шагам, отметить результат («Комфортно», «Так же», «Неприятно»), при желании написать заметку врачу, сохранить оценку.

## Действия
| Элемент | Куда ведёт |
|---|---|
| Сохранить оценку | Экран «Практика отключена» при «Неприятно», иначе возврат |
| Остановить практику | Остаётся |

## Замечание
При отзыве «Неприятно» практика блокируется в настройках. Пациент должен понимать, что это значит, текст об этом нужно проверить.
