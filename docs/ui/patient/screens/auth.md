# Вход, регистрация, восстановление

Файлы: `app/src/App.tsx` (`Auth`), `app/src/AccountSettings.tsx` (`AccessRecovery`).

## Экраны
- **Вход:** переключатель «Войти» / «Создать аккаунт», email, пароль, «Войти», «Забыли пароль?». Номер экстренной помощи 112 в заголовке формы.
- **Регистрация:** роль, имя, email, пароль (минимум 12), согласие. После входа: онбординг.
- **Восстановление:** `#/forgot`, `#/reset`, `#/verify`.

## Замечание
Маркетинговый заголовок слева на экране входа остаётся в очереди P1 из отчёта критики.
