# Врач

Маршрут: `#/doctor`. Файл: `app/src/Patient.tsx` (блок «Ваш врач»).

## Состояния
- **Врач подключён:** профиль врача (`DoctorProfileDetails`).
- **Не подключён:** текст «Врач не подключён. Добавьте приглашение в настройках.»

## Действия
| Элемент | Куда ведёт |
|---|---|
| План врача | `#/plan` (добавлено в этой правке, раньше была с главной) |

## Замечание
При отсутствии врача кнопки «Добавить приглашение» на этой странице нет, нужен переход в «Настройки».
