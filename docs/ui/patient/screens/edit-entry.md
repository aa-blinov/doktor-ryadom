# Исправление записи

Маршрут: `#/edit/:id`. Файл: `app/src/EditEntry.tsx`.

## Поля
Самочувствие, часов сна, тревога, энергия, обычные дела, небольшое действие, заметка. Четыре поля с выбором открываются отдельно, каждое выбирается ещё одним кликом.

## Действия
| Элемент | Куда ведёт |
|---|---|
| Сохранить исправления | `#/history` |
| Отмена, кнопка «История» | `#/history` |

## Замечание
Выбор через выпадающий список на каждое поле стоит два клика на изменение. Для одного значения быстрее было бы сегментированное управление, как на главной.
