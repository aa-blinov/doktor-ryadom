# Настройки

Маршрут: `#/settings`. Файл: `app/src/Patient.tsx` (`PatientSettings`).

## Блоки (сверху вниз)
1. Аккаунт: имя, тема, «Выйти из аккаунта».
2. Время для отметки: время, часовой пояс, пауза, «Сохранить настройки».
3. Доступ к записям: поле приглашения, «Проверить приглашение».
4. О себе: имя, дата рождения, что важно врачу, «Сохранить профиль».
5. Аккаунт и безопасность: установка приложения, смена пароля, выход на других устройствах, скачать данные, коды восстановления, удаление аккаунта.

## Замечание
Девять блоков в одной прокрутке. Пациенту, который не хочет разбираться, нужны только 1, 2 и 3. Блок 5 вынести на отдельную страницу.
