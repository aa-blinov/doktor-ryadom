# Отметка (отдельная страница)

Маршрут: `#/checkin`. Файл: `app/src/Patient.tsx` (`Checkin`).
Открывается из онбординга (после последнего шага) и из сводки `ReportView`, если отметки ещё нет.

## Действия
| Элемент | Куда ведёт |
|---|---|
| Настроение (5 вариантов) | Остаётся, активирует сохранение |
| Сохранить отметку | `#/saved` |

## Замечание
Путь дублирует форму на главной. Две формы отметки это лишнее место для ошибок, одна достаточна.
