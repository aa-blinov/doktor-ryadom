# Опросник

Маршрут: `#/assessment/:id`. Файл: `app/src/Care.tsx` (`AssessmentFlow`), логика в `app/src/assessments.ts`.

## Содержимое
Вопросы из назначения врача по одному или списком (PHQ-9 и другие). Пункт 9 PHQ-9 при ненулевом ответе показывает блок «Не оставайтесь с этим в одиночку» с 112.

## Действия
Ответы, кнопка сохранения. Возврат в план.
