# Сегодня

Маршрут: `#/today` (главная пациента, вкладка «Сегодня»).
Файл: `app/src/Patient.tsx` (`PatientWorkspace`, `Checkin`, `SosButton`).

## Состояния
- **Отметки за сегодня нет:** форма отметки (настроение, сон, тревога, обычные дела, заметка) и кнопка «Сохранить отметку». Кнопка неактивна, пока не выбрано настроение.
- **Отметка за сегодня есть:** заголовок «Отметка за сегодня есть», текущее настроение, кнопка «Открыть историю». Редактировать отсюда нельзя.
- **SOS:** красная (терракотовая) кнопка «Мне сейчас плохо» всегда видна. После нажатия становится «Врач получил сигнал» и неактивна.

## Действия
| Элемент | Куда ведёт |
|---|---|
| Настроение, сон, тревога, дела | Остаются на экране |
| Сохранить отметку | `#/saved` |
| Открыть историю | `#/history` |
| Мне сейчас плохо | Запрос `POST /api/patient/sos`, остаётся на экране |

## Замечания
- Ссылки «Подключить врача», «План врача», «Практики», «К приёму» убраны: есть в навигации или в истории.
- Онбординг при первом входе перекрывает экран до «Пропустить» или четырёх шагов.
