# Клики до целевых действий: пациент

Проверка: локальный стенд (`localhost:8787`), тестовый пациент без подключённого врача, 9 октября 2026. Онбординг при первом входе не учитывается, там «Пропустить» это ещё один клик.

## T1. Отметить день (2, в браузере)
1. Открыть «Сегодня».
2. Нажать настроение, например «Хорошо».
3. Нажать «Сохранить отметку». Результат: экран «Отметка сохранена».

Сон уже заполнен значением 7.5. Тревога и дела можно не выбирать, они необязательны. Кнопка «Сохранить отметку» активна сразу после выбора настроения (проверено).

## T2. Срочно сообщить врачу (1, в браузере)
1. Открыть «Сегодня» (или остаться).
2. Нажать «Мне сейчас плохо». Кнопка меняется на «Врач получил сигнал» и блокируется.

Замечание: текст говорит «получил», а письмо и пуш отправляются фоновым job, раз в минуту. Лучше написать «Сигнал отправлен».

## T3. Исправить сегодняшнюю отметку (3 или 5, частично)
После сохранения «Сегодня» показывает только «Открыть историю», формы больше нет.
1. «Открыть историю» (1).
2. «Исправить запись» у записи за сегодня (1). Появляется в браузере, кнопка есть только у записи за сегодня.
3. Текст, сон, заметка: ввод (0 кликов сверх ввода).
4. Для смены значения в выпадающем списке (самочувствие, тревога, энергия, дела): открыть список (1), выбрать (1).
5. «Сохранить исправления» (1).

Итого: 3 клика для правки текста, 5 для одного поля с выбором.

## T4. Подготовить сводку к приёму (2, по коду)
1. «Открыть историю» на «Сегодня» (1).
2. «К приёму» вверху истории (1).

Кнопка «К приёму» на истории видна в браузере. Переход взят из кода.

## T5. Пройти назначенную практику (от 4 плюс шаги, по коду)
Не проверено в браузере: у тестового пациента нет назначенных практик. Библиотека без врача пуста.
1. «Практики» в навигации (1).
2. Карточка практики (1).
3. Начать (1), шаги практики (N).
4. Выбрать отзыв «Комфортно», «Так же» или «Неприятно» (1).
5. «Сохранить оценку» (1).

## T6. Открыть план врача (2, по коду)
1. «Врач» в навигации (1).
2. «План врача» (1).

Раньше этот путь был с главной в один клик. Цена упрощения главной: +1 клик.

## T7. Подключить врача (4 плюс вставка, по коду)
1. «Настройки» в навигации (1).
2. Вставить ссылку или код в поле «Ссылка или код приглашения» (вставка).
3. «Проверить приглашение» (1).
4. Подтвердить доступ (1), по тексту блока: доступ появится только после подтверждения.

Со страницы «Врач» без подключения прямой кнопки нет, нужна «Настройки».

## T8. Выйти из аккаунта (2, по коду)
1. «Настройки» (1).
2. «Выйти из аккаунта» в блоке «Аккаунт» (1). Наличие кнопки проверено в браузере.

## T9. Сменить тему (2, по коду)
1. «Настройки» (1).
2. «Тёмная тема» в блоке «Аккаунт» (1). Наличие кнопки проверено в браузере.

## Что дало замеры
- Самый частый путь (T1) короткий: 2 клика.
- Длинные пути: T3 с выпадающими списками (5 кликов) и T7 (подключение врача, 4 клика плюс вставка). T5 зависит от числа шагов практики.
- Настройки стоят на пути T7, T8, T9: одна страница на девять блоков. Выносить блок «Аккаунт и безопасность» на отдельную страницу, тогда путь к выходу и теме не зависит от длины страницы.
