## Целевые действия

Клики считаются от открытого приложения, пользователь уже вошёл. Подробный путь и отметка проверки в [clicks.md](clicks.md).

| # | Целевое действие | Кликов | Проверено |
|---|---|---|---|
| T1 | Отметить день | 2 | в браузере |
| T2 | Срочно сообщить врачу | 1 | в браузере |
| T3 | Исправить сегодняшнюю отметку | 3 (текст) или 5 (одно поле с выбором) | частично |
| T4 | Подготовить сводку к приёму | 2 | по коду |
| T5 | Пройти назначенную практику | от 4 плюс шаги практики | по коду |
| T6 | Открыть план врача | 2 | по коду |
| T7 | Подключить врача | 4 плюс вставка ссылки | по коду |
| T8 | Выйти из аккаунта | 2 | по коду |
| T9 | Сменить тему | 2 | по коду |

Пометки: «в браузере» значит клики выполнены и экран проверен, «частично» значит часть шагов проверена, «по коду» значит путь взят из кода без нажатий.
