## Ограничения проверки

Тесты используют синтетические данные. API выполняется в тестовом процессе с настоящей SQLite; это не проверка размещённой D1 или Cloudflare runtime. Локальный Wrangler не смог открыть порт из-за политики среды. Подготовка публикации Sites не смогла подключиться к серверу исходников; запрос расширенного сетевого доступа автоматически отклонён. Приложение теперь размещено через Docker и общий Caddy: https://doktor-ryadom.duckdns.org.

Сборщик предупреждает о JS-чанке около 609 KB (около 184 KB gzip). Сборка проходит; разбиение загрузки по ролям можно выполнить при следующем расширении.

Клиническое содержание, пригодность упражнений и правила реакций требуют согласования с психиатром. Статус этих функций после расширения описан ниже.
