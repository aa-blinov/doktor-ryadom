# Пациент: библиотека практик

## Как работает

В библиотеке 12 упражнений длительностью примерно 1–3 минуты. Пациент может искать их по названию или технике, выбирать направление и длительность, оставить в списке только доступные. Карточка показывает краткое описание и источник.

По умолчанию доступны «Здесь и сейчас», «Дать имя» и «Маленькая пауза». Другие упражнения можно изучить по описанию; для выполнения врач добавляет их в план. Уже сохранённые планы не расширяются автоматически.

| Практика | Что делает пациент | Основа |
|---|---|---|
| Здесь и сейчас | Замечает опору, предметы и звуки; возвращается к действию | Заземление, ВОЗ |
| Дать имя | Называет чувство или мысль; возвращает внимание к окружающему | Замечать и называть, ВОЗ |
| Маленькая пауза | Замечает детали привычного занятия | Осознанное действие, NHS |
| Пять ориентиров | Последовательно замечает доступные ощущения; пропускает неудобные пункты | 5-4-3-2-1, NHS inform |
| Слушать мир | Прислушивается к близким и далёким звукам | Осознанность, NHS |
| Взгляд с интересом | Рассматривает детали обычного предмета | Внимание к настоящему, NHS |
| Шаг за шагом | Замечает движение при безопасной ходьбе; при необходимости остаётся сидеть | Осознанная ходьба, NHS |
| Дыхание без спешки | Дышит мягко, без форсирования и задержек | Дыхательное упражнение, NHS |
| Мысль на расстоянии | Добавляет к мысли слова «Я замечаю мысль, что…» | Освобождение от крючка, ВОЗ |
| Добрые слова | Признаёт трудность, подбирает слова поддержки и небольшое действие | Доброта к себе, ВОЗ |
| Свой ориентир | Выбирает важную сторону жизни и посильный шаг | Действия по ценностям, ВОЗ |
| Место для чувства | Сначала находит опору, затем ненадолго замечает умеренное переживание | Дать место чувствам, ВОЗ |

Названия и короткие сценарии созданы для «Рядом». Описания NHS служат общей основой для практик внимания, а не точными протоколами этих сценариев.
