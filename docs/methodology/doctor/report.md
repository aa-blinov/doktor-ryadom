# Врач: сводка перед приёмом

[Все экраны](../../METHODOLOGY.md)

Экран: `/#/patient/:id`, вкладка «К приёму».

Новые сводки отмечены в списке пациентов; их можно отобрать фильтром. Если у пациента есть непросмотренная сводка, карточка открывает эту вкладку. При нескольких отправках врач выбирает нужный период в списке.

Сначала показаны показатели за период и число полученных ответов, затем заметки и исходные записи. Сводка содержит сохранённый пациентом снимок: показатели, заметки, исходные ответы и оценки практик. Она не меняется после появления новых записей. Текущая история доступна в соседней вкладке. Если пациент пока ничего не отправлял, вкладка позволяет посмотреть сводку текущих записей без статуса отправки.

«Подтвердить просмотр» ставит отметку у конкретной сводки. Пациент увидит подтверждение при загрузке кабинета. Открытие страницы само по себе такого статуса не создаёт. Подтверждение не заменяет заключение и не означает, что врач отправил сообщение.

Доступ проверяется сервером: врач должен быть подключён к пациенту, а получателем сводки должен быть именно этот врач. После отзыва доступа просмотр и подтверждение недоступны.
