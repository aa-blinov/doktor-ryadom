# Врач: пациенты

[Все экраны](../../METHODOLOGY.md)

Экран: `/#/patients`.

## Как работает

Список содержит только пациентов, подтвердивших доступ. Для каждого показаны дата последней отметки, последнее самочувствие и число записей. Есть поиск по имени. Список не ранжирует пациентов по риску и не присваивает диагнозы.

Новые сводки показаны счётчиком; пациенты с непросмотренными сводками идут первыми. Фильтры: все, новые сводки, без отметок. Карточка с новой сводкой открывается на вкладке «К приёму»; остальные — на истории. Подтверждение просмотра — отдельное действие врача.
