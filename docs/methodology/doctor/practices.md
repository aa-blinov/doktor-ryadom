# Врач: опыт практик

[Все экраны](../../METHODOLOGY.md)

Экран: `/#/patient/:id, вкладка «Опыт практик»`.

## Как работает

Показывает название упражнения, время сохранения и оценку пациента. Неприятный опыт можно обсудить на приёме. Из этих ответов приложение не рассчитывает эффективность упражнений.
