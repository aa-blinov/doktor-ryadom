# Как устроены экраны практик

У каждой из 12 практик свой рисунок и спокойный цвет. Рисунок связан с действием, а не с диагнозом или оценкой состояния. Описание доступно в библиотеке и внутри упражнения через «Об упражнении».

| Практика | Что показывает экран | Что делает пациент |
|---|---|---|
| Здесь и сейчас | Стул и поверхность пола | Замечает опору и окружающее |
| Дать имя | Облако с линиями текста | Подбирает слова для переживания |
| Маленькая пауза | Окно и предмет | Замечает детали привычного занятия |
| Пять ориентиров | Пять связанных точек | Переключает внимание между доступными ощущениями |
| Слушать мир | Линия звука | Прислушивается к близким и далёким звукам |
| Взгляд с интересом | Лист с прожилками | Рассматривает один предмет |
| Шаг за шагом | Следы на дорожке | Замечает движение в безопасном месте |
| Дыхание без спешки | Линии воздуха | Дышит без усилия в своём темпе |
| Мысль на расстоянии | Отдельная мысль рядом с опорой | Добавляет «Я замечаю мысль, что…» |
| Добрые слова | Ладони и лист | Находит подходящие слова поддержки |
| Свой ориентир | Путь к флажку | Выбирает небольшой шаг к важному |
| Место для чувства | Свободное пространство вокруг круга | Ненадолго замечает умеренное чувство |

Рисунки выполнены в SVG: они чёткие на телефоне и ПК, не требуют загрузки изображений и имеют текстовое описание. Автоматической анимации, звука, обязательного таймера и заданного темпа дыхания нет. Переход между шагами остаётся ручным. Время — ориентир, а не требование.

Любую практику можно остановить. Оценка «Неприятно» отключает её в предложениях, как и раньше. Допуск определяется планом врача; оформление не открывает недоступные практики.

Описание — авторская адаптация, а не отдельный проверенный лечебный протокол. Основа: [руководство ВОЗ](https://www.who.int/publications/i/item/9789240003927), [осознанность NHS](https://www.nhs.uk/mental-health/self-help/tips-and-support/mindfulness/), [дыхание NHS](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/). Перед применением с пациентами врач проверяет формулировки и выбирает подходящие упражнения.

## Назначение упражнений

Пациент видит только упражнения, включённые врачом в его план. Поиск и фильтры работают внутри этого набора. Врач выбирает из всех 12 практик в плане наблюдения. Отключённая после неприятного опыта практика не показывается пациенту до возврата в настройках. Прямая ссылка не позволяет выполнить упражнение вне плана.
