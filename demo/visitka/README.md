# Видео-визитка: как это выглядит

`visitka-demo.mp4` (31 с, 1280x800, без звука). Записан с локальной копии сервиса на тестовых данных.

1. Врач загружает короткое видео в профиле (раздел «Видео-представление», до 60 с и 50 МБ, MP4 или WebM).
2. Пациент открывает карточку врача в каталоге и видит то же видео в блоке «Видео-представление».

В кадрах используется нейтральный клип-заглушка с подписью «Файл-заглушка для проверки, не врач». Настоящее видео врача пока не записано: в ролике его нет по умолчанию, врач снимает своё.
