# Демо «Рядом»

- `doctor/`: демо для врача (видео, постер, транскрипт, текст для шаринга, исходник композиции)
- `patient/`: демо для пациента, та же структура

Боль, которую закрываем: после приёма пациент уходит, и до следующего визита врач почти ничего не знает о его состоянии. Пациент остаётся один, теряет нить терапии, забывает, что хотел сказать, бросает цели. Рядом держит связь между приёмами: пациент отмечает состояние и цели, проходит опросники дома, может сразу дать знать, что плохо. Врач видит, как идёт терапия, и корректирует план по ходу, а не раз в месяц.

Чего не обещаем: приложение не ставит диагноз, не оценивает риск по баллу, не заменяет очный приём и экстренную помощь. Мы не утверждаем, что оно повышает эффективность терапии: данных об этом нет. Говорим, что оно помогает видеть ход терапии и вовремя заметить, что что-то не так.

Тексты на экране взяты из интерфейса. Имена пациентов, цели, заметки и рекомендации в роликах выдуманы.

## Как устроены ролики

Каждый ролик рассказывает историю одного пациента между двумя приёмами. Сверху идёт таймлайн по неделям (день 1, недели, приём), посередине экраны приложения, внизу субтитры. Субтитры одновременно служат транскриптом: `transcript.md` в каждой папке генерируется из того же источника.

## Пересобрать

Текст и сцены правятся в `build_demos.py`, затем:

```sh
python3 build_demos.py .
cd doctor/composition && npx hyperframes@0.8.161 check && npx hyperframes@0.8.161 render --quality looks --output ../video.raw.mp4
cd ../../patient/composition && npx hyperframes@0.8.161 check && npx hyperframes@0.8.161 render --quality looks --output ../video.raw.mp4
```

Постеры (`poster.jpg`) отдельные, в айдентике: `node posters.mjs` снимает `composition/poster.html` каждой роли. Затем `./finish.sh` ставит постер титульным экраном перед роликом: он держится 2.9 с и за 0.6 с переходит в видео. Из `video.raw.mp4` получается итоговый `video.mp4`. Сырые рендеры в git не хранятся, их даёт команда рендера выше.

Логотип в роликах тот же, что в приложении (`app/public/favicon.svg`, `Brand` в `ui.tsx`). Точка после «рядом» чуть темнее, чем в приложении (`#7c9573` вместо `#86a17c`), иначе она не проходит контраст 3:1 на фоне.
